# 💼 JobTraker

Une application Full Stack permettant de centraliser et suivre l'ensemble de ses recherches d'emploi.

Développé avec **ASP.NET Core Web API** et **Vue.js**, JobTraker offre une interface moderne permettant de gérer les candidatures, les entreprises, les entretiens et les documents associés.

---

## 🚀 Fonctionnalités

- 🔐 Authentification sécurisée (JWT)
- 👤 Gestion des utilisateurs et des rôles
- 🏢 Gestion des entreprises
- 💼 Gestion des offres d'emploi
- 📄 Suivi des candidatures
- 📅 Gestion des entretiens
- 📂 Gestion des documents
- 📊 Dashboard de suivi
- 🔎 Recherche et filtres
- 📱 Interface responsive
